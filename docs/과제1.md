# 치지직 만들기 ① 인증·인가 없는 녹화방송

> 출처: https://classroom.codemit.kr/classes/6/problems/61/submit (데브코스 백엔드 14기 16회차)

## 설명

### 목표

로그인 없이 녹화된 방송을 등록하고 시청하는 서비스를 만드세요.

### 구현 범위

- 녹화 영상과 제목을 등록합니다. 영상 파일 업로드 또는 저장된 영상 연결 방식은 자유입니다.
- 방송 목록과 상세 화면을 제공하고, 상세 화면에서 영상을 재생합니다.
- 방송 정보와 영상 위치를 저장해 다시 조회할 수 있게 합니다.
- 이번 단계에서는 인증·인가, 라이브 송출, 댓글, 도네이션을 요구하지 않습니다.

### 직접 확인

영상을 등록한 뒤 목록·상세·재생 흐름을 확인하고 재시작 후에도 등록 정보가 남는지 확인하세요.

### 제출

소스 파일·ZIP 또는 GitHub 저장소 주소로 제출하세요. README에 실행 방법, 필요한 환경변수 예시, 이번 단계의 구현 범위와 직접 확인할 절차를 적어주세요. 비밀번호·토큰 등 실제 비밀 값은 제출하지 마세요.

각 단계는 별도의 과제입니다. 다음 단계에서는 앞 단계의 기능을 유지하며 확장하세요.

## 체크리스트

### 지침 (직접 입력)

제출한 소스·설정·README만 정적으로 평가한다. 해당 단계의 필수 기능 구현과 이전 단계 기능의 유지를 확인한다. 특정 언어·프레임워크·전송 프로토콜을 강제하지 않는다. 실제 실행·영상 재생·휴대폰 연결·외부 서비스 접속·결제는 수행하지 않으며 검증했다고 주장하지 않는다. README의 확인 절차는 기재 여부만 평가한다. 실제 비밀 값을 요구하지 않는다.

### 항목 (6개)

- [ ] 소스에 문법 오류가 없다 (기본)
- [ ] 녹화 영상의 제목과 파일 또는 영상 위치를 등록하는 코드가 있다.
- [ ] 녹화방송 목록과 상세 화면 및 영상 플레이어를 구성하는 코드가 있다.
- [ ] 방송 메타데이터를 영속 저장하고 조회하는 코드가 있다.
- [ ] 로그인 없이 녹화방송 등록·조회 화면과 서버 기능을 이용하도록 구성한 코드가 있다.
- [ ] README에 실행 방법·환경변수 예시·구현 범위·직접 확인 절차가 있다.
