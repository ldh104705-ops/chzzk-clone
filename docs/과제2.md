# 치지직 만들기 ② 인증·인가 없는 휴대폰 라이브 송출

> 출처: https://classroom.codemit.kr/classes/6/problems/62/submit (데브코스 백엔드 14기 16회차)

## 설명

### 목표

1단계의 녹화방송 기능에 휴대폰 라이브 송출과 시청 기능을 추가하세요.

### 구현 범위

- 휴대폰의 카메라와 마이크를 이용해 라이브 방송을 시작하고 종료합니다.
- 시청자는 방송 목록에서 라이브 방송을 선택해 시청합니다.
- 방송 중·종료 상태를 구분해 표시합니다.
- 이번 단계에서는 로그인과 권한 검사를 요구하지 않습니다. 댓글과 도네이션도 다음 단계에서 추가합니다.
- 송출 방식과 기술은 자유롭게 선택하세요.

### 직접 확인

휴대폰에서 송출하고 다른 화면에서 시청하는 절차를 확인하세요. 카메라·마이크 권한, 접속 환경, 송출 시작·종료 확인 방법을 README에 적어주세요.

### 제출

소스 파일·ZIP 또는 GitHub 저장소 주소로 제출하세요. README에 실행 방법, 필요한 환경변수 예시, 이번 단계의 구현 범위와 직접 확인할 절차를 적어주세요. 비밀번호·토큰 등 실제 비밀 값은 제출하지 마세요.

각 단계는 별도의 과제입니다. 다음 단계에서는 앞 단계의 기능을 유지하며 확장하세요.

## 체크리스트

### 지침 (직접 입력)

제출한 소스·설정·README만 정적으로 평가한다. 해당 단계의 필수 기능 구현과 이전 단계 기능의 유지를 확인한다. 특정 언어·프레임워크·전송 프로토콜을 강제하지 않는다. 실제 실행·영상 재생·휴대폰 연결·외부 서비스 접속·결제는 수행하지 않으며 검증했다고 주장하지 않는다. README의 확인 절차는 기재 여부만 평가한다. 실제 비밀 값을 요구하지 않는다.

### 항목 (6개)

- [ ] 소스에 문법 오류가 없다 (기본)
- [ ] 1단계의 녹화방송 등록·목록·상세·재생 기능 코드가 유지되어 있다.
- [ ] 휴대폰 카메라·마이크 입력을 받아 라이브 송출을 시작하고 종료하는 코드가 있다.
- [ ] 라이브 방송 목록·시청 화면과 방송 상태를 처리하는 코드가 있다.
- [ ] 로그인 없이 송출·시청하는 구성과 휴대폰 연결·권한 설정·확인 절차가 README에 있다.
- [ ] README에 실행 방법·환경변수 예시·구현 범위·직접 확인 절차가 있다.
