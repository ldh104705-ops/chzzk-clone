# 치지직 만들기 ③ 인증·인가와 댓글

> 출처: https://classroom.codemit.kr/classes/6/problems/63/submit (데브코스 백엔드 14기 16회차)

## 설명

### 목표

녹화방송과 라이브 방송에 사용자 인증·인가와 댓글을 추가하세요.

### 구현 범위

- 회원가입·로그인·로그아웃을 구현합니다.
- 방송의 소유자를 구분하고, 방송 등록·수정·삭제 및 송출 제어에 필요한 권한을 서버에서 검사합니다.
- 로그인한 사용자가 댓글을 작성하고 방송별 댓글 목록을 조회하도록 만듭니다.
- 댓글 작성자를 구분하고 댓글 수정·삭제를 제공한다면 작성자 권한을 검사합니다.
- 시청·목록 조회의 공개 여부는 README에 설명하세요.

### 직접 확인

비로그인 사용자, 방송 소유자, 다른 사용자로 구분해 방송 제어와 댓글 작성의 허용·거절을 확인하세요. 화면에서 버튼만 숨기는 것으로 권한 검사를 대신하면 안 됩니다.

### 제출

소스 파일·ZIP 또는 GitHub 저장소 주소로 제출하세요. README에 실행 방법, 필요한 환경변수 예시, 이번 단계의 구현 범위와 직접 확인할 절차를 적어주세요. 비밀번호·토큰 등 실제 비밀 값은 제출하지 마세요.

각 단계는 별도의 과제입니다. 다음 단계에서는 앞 단계의 기능을 유지하며 확장하세요.

## 체크리스트

### 지침 (직접 입력)

제출한 소스·설정·README만 정적으로 평가한다. 해당 단계의 필수 기능 구현과 이전 단계 기능의 유지를 확인한다. 특정 언어·프레임워크·전송 프로토콜을 강제하지 않는다. 실제 실행·영상 재생·휴대폰 연결·외부 서비스 접속·결제는 수행하지 않으며 검증했다고 주장하지 않는다. README의 확인 절차는 기재 여부만 평가한다. 실제 비밀 값을 요구하지 않는다.

### 항목 (7개)

- [ ] 소스에 문법 오류가 없다 (기본)
- [ ] 녹화방송과 휴대폰 라이브 송출·시청 기능 코드가 유지되어 있다.
- [ ] 회원가입·로그인·로그아웃과 인증 상태를 관리하는 코드가 있다.
- [ ] 서버에서 방송 소유자와 인증 상태를 검사해 방송 관리·송출 제어를 제한하는 코드가 있다.
- [ ] 방송별 댓글 저장·조회 및 로그인한 작성자를 연결하는 코드가 있다.
- [ ] 서버에서 비로그인 댓글 작성을 거절하고, 댓글 수정·삭제 기능이 있다면 작성자 권한을 검사하는 코드가 있다.
- [ ] README에 실행 방법·환경변수 예시·구현 범위·직접 확인 절차가 있다.
