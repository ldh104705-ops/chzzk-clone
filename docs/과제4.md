# 치지직 만들기 ④ 도네이션

> 출처: https://classroom.codemit.kr/classes/6/problems/64/submit (데브코스 백엔드 14기 16회차)

## 설명

### 목표

3단계 서비스에 방송자를 후원하는 도네이션 기능을 추가하세요.

### 구현 범위

- 로그인한 사용자가 후원할 방송자와 금액을 선택합니다.
- 결제 서비스의 테스트·샌드박스 모드로 결제 요청과 승인 확인 흐름을 구현합니다. 실제 금전 결제는 요구하지 않습니다.
- 서버에서 결제 승인과 금액·수신 대상을 확인한 뒤 도네이션을 확정합니다. 화면의 성공 표시만으로 확정하지 마세요.
- 같은 승인 통지가 반복되어도 중복 후원으로 적립하지 않도록 처리합니다.
- 방송별 후원 내역과 합계를 표시합니다.

### 직접 확인

테스트 결제 성공·실패·취소와 승인 통지 중복 상황의 확인 방법을 README에 적어주세요.

### 제출

소스 파일·ZIP 또는 GitHub 저장소 주소로 제출하세요. README에 실행 방법, 필요한 환경변수 예시, 이번 단계의 구현 범위와 직접 확인할 절차를 적어주세요. 비밀번호·토큰 등 실제 비밀 값은 제출하지 마세요.

각 단계는 별도의 과제입니다. 다음 단계에서는 앞 단계의 기능을 유지하며 확장하세요.

## 체크리스트

### 지침 (직접 입력)

제출한 소스·설정·README만 정적으로 평가한다. 해당 단계의 필수 기능 구현과 이전 단계 기능의 유지를 확인한다. 특정 언어·프레임워크·전송 프로토콜을 강제하지 않는다. 실제 실행·영상 재생·휴대폰 연결·외부 서비스 접속·결제는 수행하지 않으며 검증했다고 주장하지 않는다. README의 확인 절차는 기재 여부만 평가한다. 실제 비밀 값을 요구하지 않는다.

### 항목 (7개)

- [ ] 소스에 문법 오류가 없다 (기본)
- [ ] 3단계의 방송·인증·인가·댓글 기능 코드가 유지되어 있다.
- [ ] 로그인한 사용자의 후원 대상·금액 선택 및 테스트 결제 요청 코드가 있다.
- [ ] 서버에서 결제 승인 결과와 금액·수신 대상을 검증한 뒤 후원을 확정하는 코드가 있다.
- [ ] 동일 결제 건의 중복 확정을 방지하는 코드와 저장 구조가 있다.
- [ ] 방송별 후원 내역과 합계를 조회·표시하는 코드가 있다.
- [ ] README에 실행 방법·환경변수 예시·구현 범위·직접 확인 절차가 있다.
